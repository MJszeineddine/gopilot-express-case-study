# Features

> Source code is private/client-confidential. Architecture and implementation details are shared at a safe case-study level.

## Verified Feature Areas

- Owner, dispatcher, merchant, and courier role surfaces
- Shipment and order workflows
- Dispatch runs, handover, delivery attempts, postponements, failures, and returns
- Role-based access and scoped operational data
- Arabic/English interface and RTL behavior
- Responsive dashboard layouts
- Public tracking by reference and PIN with restricted data exposure
- COD collection, reconciliation, settlement context, and reporting exports
- Proof-of-delivery media handling at a private-access level
- Release and deployment preparation documentation

## Explicit Non-Features

The project documentation explicitly rules out:

- GPS tracking
- Live courier maps
- Geofencing
- Background location collection
- Company fleet management
- Fuel tracking
- Vehicle maintenance modules

These exclusions are important because the system is positioned as a delivery operations platform, not a live telematics or fleet-management product.
